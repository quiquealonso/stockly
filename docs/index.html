De cero al día a día en dos minutos

Una empresa vacía: perfil y logo, categorías, un proveedor con su pedido favorito, el stock diario, un evento y el historial.

Funciones

Todo lo del almacén, nada de más

Pensada para usarse de pie, en el almacén, con una mano. En tablet y escritorio, la misma app con el menú arriba.

Stock con −/+ grandes

Cantidad, unidad y mínimo de cada producto. Un toque suma o resta; para cantidades grandes, entrada o salida de lo que quieras. Por categorías o por proveedores, lo que está bajo mínimos con un botón y el logo de tu empresa en la cabecera.

Agua mineral 50clBebidas · mín. 48−72+
MerluzaCarnes y pescados · mín. 3−1,5+
Arroz bombaDespensa · mín. 5−8+

Pedidos favoritos

Lo que pides siempre, con sus cantidades. Copia la lista para enviarla y, al recibirla, súmala al stock en un paso.

Proveedores

Un producto puede venir de varios proveedores: el recuento es uno solo. Con teléfono y notas.

Eventos

Apunta el consumo y descuéntalo una vez. Si falta stock no descuenta nada; los comensales dan el ratio por persona.

Control

Cada movimiento con quién, cuándo y por qué: ajuste, pedido, evento, corrección o alta. Lo escribe la base de datos.

Pantallas

Hecha para el móvil, primero

Botones de 44 px como mínimo, textos a 16 px y respeto por el notch y la barra de gestos. Desliza para ver más.

El día a día

Se monta en una tarde, se usa cada día

  1. Alta

    El administrador crea la empresa y da acceso a cada persona del equipo.

  2. Perfil

    Nombre, datos fiscales y logo, que sale en la cabecera.

  3. Catálogo

    Categorías, proveedores y productos con su mínimo.

  4. Pedidos

    Llega la mercancía: «Recibido» y se suma todo al stock.

  5. Eventos

    Apunta el consumo y descuéntalo cuando esté bien.

  6. Control

    Revisa los movimientos y lo que está bajo mínimos.

Técnica

Sin backend propio, sin atajos

El front habla directamente con Supabase. Lo que tiene que ser seguro y consistente vive en PostgreSQL.

  • Angular 22 standalone con signals, CSS propio y mobile-first.

  • Supabase: PostgreSQL, Auth y API REST vía supabase-js.

  • RLS: solo entra el personal de la tabla staff.

  • Funciones atómicas: dos personas tocando el mismo producto no se pisan.

  • Capacitor: APK de Android con el mismo front.

  • Demo y vídeo: modo con datos ficticios en memoria y grabación automática con Playwright.

Empezar

Tu instalación en cuatro pasos

Un proyecto gratuito de Supabase basta. Detalle completo en el README.

Base de datos

Crea un proyecto en Supabase y ejecuta supabase/schema.sql en el SQL Editor. Opcional: seed.sql con datos de ejemplo.

Esquema

Añade aletes en Settings › Data API › Exposed schemas.

Equipo

Crea los usuarios en Authentication › Users y dales acceso:

insert into aletes.staff (email)
  values ('persona@empresa.com');
insert into aletes.companies (name)
  values ('Mi restaurante');

Front

Configura las claves públicas y arranca:

cd frontend
cp src/environments/environment.ts \
   src/environments/environment.local.ts
# rellena supabaseUrl y supabaseAnonKey
npm install && npm start
npm run apk   # Android

Pruébala ahora, con datos de mentira

Toca, recibe pedidos y descuenta eventos. Nada sale de tu navegador y al recargar vuelve a empezar.
